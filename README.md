# RR Cadastral Bot

Бот подключается к уже открытому Chrome через `--remote-debugging-port=9222`, читает кадастровый номер МКД из `N2`, собирает данные с НСПД, Росреестра и ГИС ЖКХ и пишет результат в текущий активный лист Google Sheets.

Полный режим использует турбо-схему: НСПД один раз отдаёт карточку и список объектов дома, бот отбрасывает кадастры из чужого квартала, затем Росреестр заполняет C:F, H и I:L. После этого НСПД подробно проверяет только нежилые помещения ради признака ОДИ в G. Жилые карточки НСПД по одной не запрашиваются. Запись в Google Sheets выполняется пачками. Технические ошибки сервисов не записываются как подтверждённое отсутствие объекта.

Карточки и список дома НСПД кэшируются на 24 часа. При повторном запуске бот использует свежий кэш и запрашивает только отсутствующие или просроченные кадастры. Для полного обхода кэша включите в приложении «Обновить НСПД без кэша» или передайте `--refresh-nspd`.

## Подготовка

0. На новом компьютере установите Node.js LTS: https://nodejs.org/

1. Запустите Chrome:

```bat
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\chrome-remote" --profile-directory=Default
```

2. В этом Chrome авторизуйтесь в Google Sheets и Росреестре.
3. Откройте нужную Google-таблицу. НСПД и Росреестр бот откроет сам, если вкладки не найдены.
4. Распакуйте архив в папку без кириллических спецсимволов в пути, например `C:\rr-cadastral-bot`.
5. Запустите `запуск-бота.bat`.
   При первом запуске батник сам выполнит `npm install` и поставит легкую зависимость `playwright-core`.
6. Введите строку, с которой продолжить. Для первого запуска это `2`.

## Как работает продолжение

Если указать строку `2`, бот начинает с первого помещения/машино-места и пишет в `A2:K2`.
Если указать строку `40`, бот заново считывает список объектов с НСПД, пропускает первые `38` объектов и продолжает с объекта номер `39`, записывая его в `A40:K40`.

Если НСПД уже собран и надо продолжить только зеленые колонки через Росреестр, запускайте:

```bat
запуск-только-росреестр.bat
```

и указывайте строку, с которой продолжить Росреестр.

## Важные замечания

- Быстрый режим сохраняет локальную контрольную точку и может продолжить незавершённое задание.
- При трёх технических отказах РР подряд бот перезагружает страницу. Если после перезагрузки завершилась сессия, это явно выводится в журнал; после входа через ЕСИА запуск продолжается с контрольной точки.
- Ошибочные строки РР автоматически повторяются после основного прохода, а прогресс сохраняется каждые 10 обработанных объектов.
- Результаты записываются блоками, что заметно ускоряет работу с Google Sheets.
- Режимы «Росреестр: нежилые» и «Общее имущество» читают B:C одним диапазоном, заранее формируют список нежилых и не обходят таблицу по одной строке.
- Общее имущество собственников подсвечивается бледно-желтым по `A:K`.
- Несколько прав из Росреестра записываются в одну ячейку через перенос строки.
- В полном режиме подробные запросы НСПД выполняются только для нежилых объектов после их классификации Росреестром.
- Кадастры из квартала, отличного от квартала МКД, не отправляются в Росреестр.
- Chrome на новом компьютере должен быть открыт с `--remote-debugging-port=9222`; обычная вкладка Chrome без этого режима не подойдет.
- Для безопасной диагностики без записи можно выполнить `node start.js 2 --dry-run --max-items=3`.
