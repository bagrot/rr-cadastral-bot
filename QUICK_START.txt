Кадастробот: быстрый старт
===========================

ОБНОВЛЕНИЯ

При запуске программа сама проверяет новую версию. Если обновление найдено,
в правой части верхней панели появится кнопка «Обновить до ...».
Нажмите её, дождитесь загрузки и подтвердите запуск установщика.
Во время активного сбора данных обновление не запускается.

1. Запустите установщик RR-Cadastral-Bot-Setup.exe.
2. Откройте приложение «Кадастробот».
3. Нажмите «Открыть Chrome».
4. В открытом Chrome авторизуйтесь в Google, Росреестре и ГИС ЖКХ.
5. Нажмите «Открыть сервисы».
6. Проверьте, что в Google Sheets в N2 указан кадастр МКД.
7. Выберите режим запуска.

Для максимальной скорости оставляйте «Обновить НСПД без кэша» выключенным.

Node.js устанавливать отдельно не нужно: runtime встроен в приложение.


Кнопки
------

1. Открыть Chrome
Открывает правильный Chrome:

"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\chrome-remote" --profile-directory=Default

2. Открыть сервисы
Открывает Google Sheets, НСПД, Росреестр и ГИС ЖКХ.

3. Начать полный сбор
НСПД быстро получает карточку дома и общий список объектов.
Чужие кадастры из другого квартала отбрасываются до Росреестра.
Росреестр заполняет C:F, H, I:L и P2.
Затем НСПД проверяет только нежилые помещения и заполняет для них ОДИ в G.
Жилые карточки НСПД по одной не открываются — это значительно ускоряет сбор.
ГИС ЖКХ заполняет Q2.
Незавершённый запуск можно продолжить с контрольной точки.
Если Росреестр перенаправил на ЕСИА, войдите и запустите режим снова:
повторный сбор НСПД не потребуется.
При массовом отказе РР бот сам перезагрузит его страницу и повторит ошибки.
Если перезагрузка завершила авторизацию, сообщение об этом появится в журнале.
Список дома и проверенные карточки нежилых хранятся локально 24 часа.

4. Данные НСПД
Заполняет только данные НСПД: A:H, M2 и O2.
Колонки I:L не очищаются.
Полностью перечитывает карточки всех объектов; для большого дома это долго.

5. Росреестр: все объекты
Обновляет P2 и Q2, затем проверяет строки начиная со стартовой.

6. Росреестр: нежилые
Одним чтением получает B:C, сначала формирует список строк со значением
«Нежилое», затем проверяет в РР только готовый отфильтрованный список.

7. Проверить строки
Проверяет только заданные строки.
Примеры: 2-122 | 2-122, 123-127 | 5, 9, 12-20

8. Общее имущество
Одним чтением получает текущие B:C, сначала формирует список нежилых,
проверяет в НСПД только этот список и пачками обновляет G.


Колонки
-------

A  Номер по порядку
B  Кадастровый номер помещения или машиноместа
C  Назначение
D  Этаж
E  Площадь
F  Форма собственности
G  Общее имущество
H  Полный адрес объекта
I  Тип собственности
J  Дата права
K  Номер права
L  Статус
M2 Год постройки
N2 Кадастр МКД
O2 Площадь ПКК
P2 Площадь РР
Q2 Площадь ГИС ЖКХ


Ссылки
------

Во вкладке «Источники» можно заменить ссылку на Google-таблицу
или адреса сервисов без дополнительного пароля.
После изменения нажмите «Сохранить ссылки».
Настроенные ссылки сохраняются при обновлении программы.


Если бот не подключается
------------------------

1. Закройте специальный Chrome.
2. Запустите Chrome через кнопку в приложении.
3. Откройте нужные вкладки.
4. Авторизуйтесь в сервисах.
5. Запустите режим снова.
